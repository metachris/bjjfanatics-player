# BJJ Fanatics Courses

Local video players for purchased BJJ Fanatics courses.

## Courses

- [Anaconda Strangle — John Danaher](anaconda/index.html)
- [Omoplata — John Danaher](omoplata/index.html)
- [Enter The System: Front Headlocks — John Danaher](front-headlock/index.html)

## Usage

Open any `index.html` in a browser to watch locally downloaded videos.

Use the `chapter` URL parameter to open a specific chapter. The value matches the
chapter number shown in the playlist, for example `anaconda/index.html?chapter=2.3`.
The URL updates automatically when you select a chapter, so it can be copied and shared.

### Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Space / K | Play/pause |
| F | Fullscreen |
| J | Skip back 10s |
| L | Skip forward 10s |
| ← | Skip back 5s |
| → | Skip forward 5s |
| N | Next chapter |
| P | Previous chapter |
| < | Decrease playback rate |
| > | Increase playback rate |
| 0–9 | Seek to 0%–90% of video |
| / | Search chapters |
| ? | Show keyboard shortcuts |
